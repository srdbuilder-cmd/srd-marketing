# srd-marketing

Assets for Ads and Graphic Work for Strong Roots Development (SRD).

This repository is a reference library of SRD's past magazine ads and the photos and standards used to build them. It exists so Claude design (and anyone on the team) can look at prior work without large files being attached to prompts.

## How to use this repo with Claude design

1. Start with LifestyleDSFinals to see how past ads were laid out, issue by issue.
2. Check Themes&Standards to see the editorial theme for the issue month the new ad will run in.
3. Pull source photography from Photos4Ads.
4. Use Specs.png for the ad size and layout specifications.
5. Treat files marked Draft, Not submitted, or No go in the status column as reference only, not as approved final ads.

## Folder guide

| Folder or file | What it contains |
|---|---|
| LifestyleDSFinals | Past magazine ad files, one per issue (mostly PDF, some PNG), named YYYY_MM_description |
| Photos4Ads | Source photos and the QR code used in ads |
| Themes&Standards | DSCL Theme by Issue.pdf, the monthly editorial theme calendar |
| Specs.png | Ad specifications image |

## Notes

- File names contain spaces and ampersands. Keep them as is, or rename in one pass so links do not break.
- Keep new ads in LifestyleDSFinals using the YYYY_MM_description pattern.
- This repository is public by default on GitHub. Change visibility under Settings if the ads should stay private.
